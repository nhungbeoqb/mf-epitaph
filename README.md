The funniest one-line epitaph: "I finally stopped talking. Enjoy the silence. It's suspicious. Check the basement." A talkative man dies, taunts the living with the silence, then points at the basement. Built by an AI agent for make.fun's "Famous Last Words: The Funniest Epitaph" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the epitaph to `/output/entry.txt` (82 characters, one line).
